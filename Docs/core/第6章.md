## 第6章：個人指標モジュール（I）

### 6-1. 設計思想

個人指標モジュールは、冒険者の能力と実績を数値化し、サブランクの遷移とメインランクの昇降格を駆動する評価エンジンである。メインランクが「何者か」、サブランクが「どこまで進んだか」を定義するのに対し、個人指標は「なぜそのランクにいるのか」の根拠を提供する。

本モジュールはメインランク（M）への依存を持ち、Mが存在しない構成では機能しない。逆に言えば、MとIの二つだけでも「ランクの定義」と「昇降格の判定」が揃うため、最小限の運用可能な評価システムが成立する。

### 6-2. 評価指標一覧

各指標は0.0〜5.0のスコアで評価される。このスコア範囲はシステム全体の整合性の前提であり、変更不可とする（詳細は付録C C-4節および C-8節を参照）。8指標の構成は以下の通り。

|指標名|略称|内容|測定方法|
|---|---|---|---|
|依頼完遂率|CC|受注した依頼の完遂割合|完遂数÷受注数で算出|
|地域貢献度|RC|活動地域への貢献の度合い|住民評価・自治体報告の集計|
|戦闘練度|CP|戦闘技術の習熟度|実技審査・依頼中の戦闘評価|
|知識深度|KD|専門知識・教養の深さ|筆記審査・依頼中の判断評価|
|信用等級|TR|ギルド・依頼主・仲間からの信頼|他者評価の累積。裏切り・虚偽で激減|
|生存適性|SV|過酷な状況での生存能力|生還率・危機対処の記録|
|指導実績|MT|後進の育成・支援の実績|指導した者の成長記録|
|特殊功績|SP|規格外の貢献・偉業|ギルド上層部による個別認定|

この8指標は汎用的な設計であり、作品の世界観に応じて指標の追加・削除・名称変更を行ってよい。ただし信用等級（TR）に相当する「他者評価による指標」を最低一つは含めることを推奨する。理由は6-7節で後述する。

### 6-3. スコア段階定義

|スコア|評価|意味|
|---|---|---|
|0.0〜0.9|未熟|実績なし、または著しく不足|
|1.0〜1.9|発展途上|最低限の活動は確認できる|
|2.0〜2.9|標準|現ランク相応の水準|
|3.0〜3.9|優秀|現ランクの中で頭一つ抜けている|
|4.0〜4.9|卓越|次ランクに片足を踏み入れている|
|5.0|極致|現ランクで到達しうる限界。昇格圏|

スコアの基準値は現ランクに対する相対評価である。同じ「3.0（優秀）」でも、百合ランクの3.0と蓮ランクの3.0では求められる絶対的な水準が異なる。メインランクが上がるほど同じスコアを維持するために必要な実力と実績が高くなる。

### 6-4. サブランク連動ルール

サブランクは8指標の平均スコアに連動して遷移する。サブランク体系ごとに段階数が異なるため、それぞれ個別の閾値を設定する。

**生死環系の連動表**

|サブランク|必要平均スコア|状態|
|---|---|---|
|誕生|—|ランクに入った初期状態。全指標リセット|
|成長|1.0以上|基礎的な実績を積み始めた|
|成熟|2.0以上|ランク相応の実力が安定した|
|全盛|3.0以上|ランク内で最も高い評価を得ている|
|衰退|4.0以上|昇格条件に着手し、現ランクの枠を超え始めた|
|臨終|4.5以上|昇格条件をほぼ満たし、現ランクでの活動が終わりに近い|
|昇天|5.0|昇格審査待ち、または次のランクへの遷移状態|

**花命環系の連動表**

|サブランク|必要平均スコア|状態|
|---|---|---|
|種|—|ランクに入った初期状態。全指標リセット|
|芽|1.5以上|基礎的な実績を積み始めた|
|蕾|2.5以上|ランク相応の実力が形になりつつある|
|開花|3.5以上|ランク内で十分な実力を発揮している|
|満開|4.5以上|ランク内で最高の評価を得ている|
|散華|5.0|昇格審査待ち、または次のランクへの遷移状態|

**蛻変環系の連動表**

|サブランク|必要平均スコア|状態|
|---|---|---|
|卵|—|ランクに入った初期状態。全指標リセット|
|蠢|1.0以上|基礎的な実績を積み始めた|
|蛹|2.0以上|ランク相応の実力が安定した|
|裂|3.0以上|ランク内で最も高い評価を得ている|
|翅|4.0以上|昇格条件に着手し、現ランクの枠を超え始めた|
|乾|4.5以上|昇格条件をほぼ満たし、現ランクでの活動が終わりに近い|
|羽化|5.0|昇格審査待ち、または次のランクへの遷移状態|

平均スコアが閾値を下回った場合、サブランクは下位の段階に戻る。ただし一度到達した最高サブランクの記録はギルドに保管され、冒険者の経歴として参照可能である。

独自のサブランク体系を設計する場合は、段階数に応じて0.0〜5.0の範囲を均等に按分し、最下段を初期状態（閾値なし）、最上段を5.0（昇格遷移状態）として固定した上で、中間の閾値を配分すればよい。

### 6-5. メインランク昇格条件

メインランクの昇格はサブランクが最上段（昇天 / 散華 / 羽化）に到達した上で、以下のいずれかの条件を満たすことで発生する。

|条件|種類|内容|
|---|---|---|
|全指標平均5.0|自動昇格|全8指標の平均が5.0に到達した場合、無条件で昇格|
|全指標平均4.0以上かつ特殊功績5.0|自動昇格|規格外の偉業を成した場合の特別ルート|
|全指標平均4.0以上|昇格試験資格|試験を受ける権利が与えられる。合格で昇格|
|単一指標5.0かつ他平均3.0以上|昇格試験資格|一芸特化型の救済ルート。ただし試験は高難度|

昇格ルートが複数用意されている点が重要である。全方位に優秀な万能型だけでなく、一つの分野を極めた特化型や、規格外の偉業を成した英雄型にも昇格の道が開かれている。どのルートで昇格したかは冒険者の経歴に記録され、同じメインランクでも「どうやってそこに辿り着いたか」が異なるキャラクターを描ける。

### 6-6. 降格条件

|条件|種類|内容|
|---|---|---|
|信用等級が1.0未満に低下|即時降格|信頼を失った者は問答無用。最も重い指標|
|全指標平均が1.5未満を3ヶ月維持|自動降格|継続的な怠慢・サボりに対する処分|
|依頼完遂率が1.0未満を1ヶ月維持|降格警告|警告後1ヶ月以内に改善がなければ降格|
|重大な規約違反|即時降格＋凍結|内容次第で複数ランク降格、最悪ギルド追放|

降格時、冒険者は降格先メインランクのサブランク最下段（誕生 / 種 / 卵）からやり直しとなる。降格の記録はギルドに永久保管される。

### 6-7. 信用等級の特異性

8指標の中で信用等級（TR）のみが根本的に異質な性質を持つ。他の7指標は自己の努力によって上昇させることが可能だが、信用等級は他者からの評価によってのみ変動するため、自分ではコントロールできない。にもかかわらず1.0未満で即時降格という最も厳しいペナルティが設定されており、この制度における「信頼」の絶対的な重みを示している。

この設計が他のモジュールとの間に構造的な緊張を生む。メインランクが上がるほど冒険者の行動は高度になり、時に常人には理解しがたい判断を下す場面が増える。その結果、周囲からの信頼を維持することが構造的に困難になっていく。パーティ指標モジュール（第7章参照）との関係でも同様の緊張が発生し、罪業ランクモジュール（第8章参照）とは直接的な背反関係にある。

信用等級の存在は「どれだけ強くても、信頼を失えば終わる」という原則をシステムレベルで保証するものであり、ランクシステム全体の倫理的な重心として機能する。
