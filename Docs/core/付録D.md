### D-10. 使用ガイド

**最小構成（Mのみ）の場合。** D-1、D-2、D-3、D-9のみを使用する。他のセクションは全て削除してよい。

**標準構成（M＋S＋I）の場合。** D-1からD-5およびD-9を使用する。D-6、D-7、D-8は削除してよい。

**関係性重視構成（M＋S＋I＋PD＋PW）の場合。** D-1からD-7およびD-9を使用する。D-8は削除してよい。

**裏社会構成（M＋S＋I＋CR）の場合。** D-1からD-5、D-8、D-9を使用する。D-6、D-7は削除してよい。

**フル構成（全モジュール）の場合。** 全セクションを使用する。

**独自指標を追加した場合。** D-5の指標テーブルに行を追加し、略称とスコア欄を記入する。8指標平均の欄は指標数に応じて再計算する。

**系統運用方式について。** D-3の系統運用方式は作品単位で統一する。同一作品内の全キャラクターシートで同じ方式が選択されていることを確認する。キャラクター個別選択方式の場合のみ、キャラクターごとに系統の選択が異なる。
