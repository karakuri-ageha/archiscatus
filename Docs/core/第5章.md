## 第5章：サブランクモジュール（S）

### 5-1. 設計思想

サブランクはメインランク内の進行度を示す拡張モジュールである。メインランクが「何者であるか」を定義するのに対し、サブランクは「そのランクの中でどこまで進んだか」を示す。これにより同じメインランクの冒険者同士でも異なる重みを持つことになる。

サブランクの設計においては、名称の本来の意味と作中での意味を明確に分離する。サブランク名は雰囲気を伝えるラベルであり、人生の段階そのものを意味するわけではない。

|要素|役割|例|
|---|---|---|
|名称|呼び名。進行度の雰囲気を伝える|誕生、成長、全盛、昇天 等|
|本来の意味|その言葉が一般的に持つ意味|「誕生」＝生命がこの世に生まれ出ること|
|作中の意味|ランクシステム内での機能的な意味|「誕生」＝そのランクに入ったばかりの初期状態|

この分離により、名称の持つ情緒的な響きを活かしつつ、システムとしては純粋な進行度指標として運用できる。フレーバーとしての本来の意味は設定資料に記載しておけば、作者が物語に滲ませたいときに自由に使える。

### 5-2. 生死環系サブランク

龍姫式の剛獣系・妖美系メインランクとの併用を想定したサブランク体系。7段階。命の流れを模した名称を持つが、作中では純粋にランク内の進行度を表す。

|サブランク|名称|本来の意味|作中での意味|
|---|---|---|---|
|7（最下段）|誕生|生命がこの世に生まれ出ること|そのランクに入ったばかりの初期状態|
|6|成長|心身が発達し大きくなること|基礎的な実績を積み始めた段階|
|5|成熟|十分に発達し安定すること|ランク相応の実力が安定した段階|
|4|全盛|力や勢いが最も盛んな時期|ランク内で最も高い評価を得ている段階|
|3|衰退|力が陰り弱まっていくこと|昇格条件に着手し、現ランクの枠を超え始めた段階|
|2|臨終|命が尽きる間際|昇格条件をほぼ満たし、現ランクでの活動が終わりに近い段階|
|1（最上段）|昇天|魂が天へ昇ること|昇格審査待ち、または次のランクへの遷移状態|

### 5-3. 花命環系サブランク

彼岸花式メインランクとの併用を想定したサブランク体系。6段階。花の一生を模した名称を持つが、作中では純粋にランク内の進行度を表す。

|サブランク|名称|本来の意味|作中での意味|
|---|---|---|---|
|6（最下段）|種|植物の繁殖体|そのランクに入ったばかりの初期状態|
|5|芽|種から最初に出る成長点|基礎的な実績を積み始めた段階|
|4|蕾|開花前の閉じた花|ランク相応の実力が形になりつつある段階|
|3|開花|花が開くこと|ランク内で十分な実力を発揮している段階|
|2|満開|全ての花が開いた状態|ランク内で最高の評価を得ている段階|
|1（最上段）|散華|花が散ること。仏教では供花の意も|昇格審査待ち、または次のランクへの遷移状態|

### 5-4. 蛻変環系（ぜいへんかんけい）サブランク

龍姫式の神仙系メインランクとの併用を想定したサブランク体系。7段階。昆虫の完全変態を模した名称を持つが、作中では純粋にランク内の進行度を表す。

昆虫の変態をサブランクの基盤に据える理由は三つある。第一に、「羽化登仙」という語が昆虫の羽化と仙人への変容を同時に指すという文化的符合。神仙思想と昆虫変態は「羽化」の一語で自然に接続される。第二に、昆虫の変態が「同じ存在が全く別の形になる」プロセスであること。芋虫と蝶が同一の生命体であるという事実は、境界上で変容していく神仙系の核心テーマそのものである。第三に、昆虫の変態が持つ「不気味だが神秘的」という質感。生死環系の温かみ、花命環系の美しさとは異なる第三の質感として、神仙系の「人でも神でもない境界の存在」と通底する。

|サブランク|名称|読み|本来の意味|作中での意味|
|---|---|---|---|---|
|7（最下段）|卵|らん|全てが閉じ込められた殻。生命の設計図は既に内包されているが、まだ何も始まっていない|そのランクに入ったばかりの初期状態|
|6|蠢|しゅん|蠢く。虫が動き出すこと。目覚めた後の最初の動き|基礎的な実績を積み始めた段階|
|5|蛹|よう|外から見れば完全に静止しているが、内部では幼虫の体が一度完全に溶解し、全く新しい構造として再構成されている|ランク相応の実力が安定した段階|
|4|裂|れつ|殻が裂けること。蛹の内側で完成した新しい形が、古い殻を内側から破る瞬間|ランク内で最も高い評価を得ている段階|
|3|翅|し|羽化直後の翅はまだ縮んでおり、体液が送り込まれて徐々に伸展する。飛べる体はあるが、まだ飛べない時間|昇格条件に着手し、現ランクの枠を超え始めた段階|
|2|乾|かん|翅が乾くこと。伸びきった翅が硬化するのを待つ時間。この間は外敵に対して最も無防備になる|昇格条件をほぼ満たし、現ランクでの活動が終わりに近い段階|
|1（最上段）|羽化|うか|完全変態の完了。もう元の形には戻れない。道教では「羽化登仙」として仙人への変容を意味する|昇格審査待ち、または次のランクへの遷移状態|

### 5-5. 三体系比較

|比較軸|生死環系|花命環系|蛻変環系|
|---|---|---|---|
|テーマ|命の時間|花の一生|虫の変態|
|段階数|7|6|7|
|始点|誕生（生まれ出る）|種（眠っている）|卵（閉じている）|
|終点|昇天（天へ昇る）|散華（花が散る）|羽化（別の形になる）|
|中間の核心|全盛（力の頂点）|開花（花が開く）|蛹（全身が溶ける）|
|最も痛い遷移|全盛→衰退（頂点から踏み出す）|満開→散華（美を手放す）|裂→翅（出たのにまだ動けない）|
|循環の質感|温かい。人の命の重み|美しい。花の儚さ|不気味で神秘的。虫の異質さ|
|不可逆性の質|場所の不可逆（天に昇ったら戻れない）|時間の不可逆（散った花は咲かない）|存在の不可逆（元の形には戻れない）|
|推奨接続先|剛獣系・妖美系|彼岸花式|神仙系|

推奨接続先はあくまで質感の響き合いに基づく推奨であり、技術的にはどのメインランクにどのサブランク体系を接続しても機能する。ただし推奨と異なる接続を行う場合、メインランクとサブランクの質感に乖離が生じる可能性があることに留意する。

### 5-7. 構造上の特異点

マトリクス上には、物語的に特別な重みを持ちうる座標が存在する。これらはシステム上の特殊ルールではなく、フレーバーとして設定資料に記載しておくことで、作者が物語に活用できる要素である。

#### 5-7-1. 各体系共通の特異点

全てのサブランク体系に共通する構造的な特異点を以下に示す。

|座標パターン|特異性|
|---|---|
|各ランクのサブランク第4段階→第3段階の境界|ランク内で最高評価の段階から、昇格条件に着手する段階への遷移。フレーバーとしては「力の頂点から次へ踏み出す決断」を意味しうる。生死環系では「全盛→衰退」、花命環系では「満開→散華」（第2段階→第1段階）、蛻変環系では「裂→翅」|
|各ランクのサブランク最上段|昇格審査待ち、または次のランクへの遷移状態。フレーバーとしては「今の自分を終わらせて次の自分になる」瞬間|
|各系統の最終座標|最上位メインランクのサブランク最上段。「その先に何があるのか」という問いが世界観の謎として残される|
|三系統の対照座標|同じランク番号・サブランクに位置する三系統の座標の組。システム上は同等の進行度だが、フレーバーとしては全く異なるドラマを内包する|

#### 5-7-2. 生死環系の特異点（剛獣系・妖美系）

|座標|特異性|
|---|---|
|全盛→衰退の境界|生死環系で最も物語的に重い遷移。力の頂点にいる者が、次のランクへ向かうために「衰退」の名を受け入れる瞬間|
|臨終→昇天の遷移|現ランクでの活動がほぼ終わり、次のランクへの遷移状態に入る境界。「今の自分が死に、次の自分が生まれる」|
|龍・昇天 / 姫・昇天|各系統の最終座標。龍・昇天は「天に昇った先に何があるのか」、姫・昇天は「名を超えた先に何があるのか」という問い|
|鬼・全盛 と 鬼女・全盛|対照座標の代表例。制御不能な暴力の頂点と、愛が反転した破壊の頂点。系統間の対比が最も鋭い座標の一つ|

#### 5-7-3. 花命環系の特異点（彼岸花式）

|座標|特異性|
|---|---|
|満開→散華の境界|ランク内最高評価から昇格遷移状態への移行。「最も美しい瞬間の自分を手放す決断」|
|蓮・散華 → 彼岸花・種|全54段階の中で最も物語的な重みを持ちうる遷移。「汚濁を糧にできる者が自らを散らし、死後の花の種になる」瞬間|
|彼岸花・満開|全体の最上位から一つ手前。システム上は最高評価だがまだ散華が残っている。「死を超えた者がさらに散るとはどういうことか」という問い|

#### 5-7-4. 蛻変環系の特異点（神仙系）

|座標|特異性|
|---|---|
|裂→翅の境界|蛻変環系で最も劇的な遷移。殻を破った直後、翅はまだ濡れていて飛べない。生死環系の「全盛→衰退」が頂点から踏み出す決断、花命環系の「満開→散華」が美を手放す決断であるのに対し、蛻変環系の「裂→翅」は「出たのにまだ動けない苦しみ」。手放す痛みではなく、待つことの痛み|
|壺・蛹|神仙系中位×蛻変環系中間。内外の境界が曖昧な存在の中身が完全に溶解している状態。全63座標の中で最も「何が起きているかわからない」座標|
|道・羽化|神仙系の最終座標。「名づけえぬものが羽化するとは何か」。龍・昇天が「天の先に何が」、姫・昇天が「名の先に何が」であるのに対し、道・羽化は「定義以前のものが別の形になるとは、そもそも何が変わるのか」。最も解の出ない問い|
|虚・蛹|空っぽの存在が蛹になる。溶解するはずの中身がない。二重の不在から何が再構成されるのか|
|夢・卵|自他の境界が溶けた者がまた殻の中に閉じ込められる。夢のランクに新たに到達した瞬間、全てがリセットされて卵に戻る。「夢から覚めたら卵の中だった」という入れ子構造|
|童・蛹|成長を拒む存在が蛹の中で溶解する。成長しないことを選んだ者が、意志に反して全身を溶かされる|
|翳・翅|メインランク「翳（かげり）」とサブランク「翅（し）」の組み合わせ。光が陰り始めた者が、まだ飛べない翅を持っている。陰りゆく者が翅を得るという逆説|

#### 5-7-5. 三系統横断の特異点

三系統のマトリクスを横断して見た場合に、特に対照的な意味を持つ座標の組を以下に示す。

|座標群|対照の内容|
|---|---|
|龍・昇天 / 姫・昇天 / 道・羽化|三系統の最終座標。昇天は場所の移動（天へ）、羽化は存在の変態（別の形へ）。三つの終わり方が全て異なる|
|鬼・全盛 / 鬼女・全盛 / 翳・裂|第7位×サブランク第4段階。制御不能な暴力の頂点、愛の反転破壊の頂点、陰りゆく者が殻を破る瞬間。三つの「最も危険な状態」|
|鵺・誕生 / 鬼女・誕生 / 壺・卵|第5位×サブランク最下段。混沌に入ったばかりの者、反転した愛に入ったばかりの者、内外の境界が消えたばかりの者。三つの「崩壊の始まり」|

### 5-8. 独自サブランクの作り方

メインランクと同様に、自分の作品に合わせて独自のサブランクを設計することもできる。その場合は以下の指針を推奨する。

**段階数の目安。** メインランクが多い場合はサブランクを少なく（3〜4段階）、メインランクが少ない場合はサブランクを多く（6〜7段階）設定することで、総段階数のバランスを取る。

**名称の選び方。** 一つのテーマで統一された連続的な変化を表す言葉を選ぶ。生死環系なら「命の流れ」、花命環系なら「花の一生」、蛻変環系なら「虫の変態」。重要なのは名称の本来の意味と作中での意味を分離して定義することであり、名称はあくまで雰囲気を伝えるラベルとして扱う。

**最下段と最上段の関係。** 最下段は「そのランクに入った初期状態」、最上段は「次のランクへの遷移状態」として固定する。この二つが固定されていれば、中間の段階は自由に設計できる。

**メインランクとの質感の響き合い。** サブランクの名称テーマは、接続先のメインランクの質感と響き合うものを選ぶことを推奨する。獣には命の時間を、花には花の一生を、概念には変態の神秘を。ただしこれは推奨であり、意図的に異なる質感を組み合わせることで独自の効果を狙うことも可能である。
