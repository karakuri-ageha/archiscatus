## 第0章：Archiscatus

### 0-1. 正式名称

本資料体系の正式名称は **Archiscatus**（アルキスカトゥス）である。

Archiscatusはラテン語の造語であり、三つの語根で構成される。

|語根|由来|意味|
|---|---|---|
|Archi-|Architectura（建築術）|設計する、構築する|
|-sca-|Scala（梯子・階段）|段階、階梯|
|-tus|Textus（織物・テキスト）|織り上げられたもの、編まれたもの|

三つを合わせた意味は「段階を織り上げる設計術」。

また-tusというラテン語の過去分詞語尾により、「設計され、段階づけられ、織り上げられたもの」という完了の含意を持つ。Archiscatusは方法論であると同時に、その方法論によって既に織り上げられた成果物でもある。

### 0-2. なぜ独自の名称を持つのか

本資料は第1章において、ランク名の設計方向を「即時理解型」と「独自命名型」の二つに分類している。即時理解型は説明不要で直感的だが没個性であり、独自命名型は初見で意味がわからない代わりに世界観の深度と物語の駆動力を獲得する。

Archiscatusという名称はこの設計思想を資料自体に適用したものである。「ランクシステム設計資料」という即時理解型の対外名称を持ちつつ、Archiscatusという独自命名型の正式名称を内部に持つ。読者がこの名前に出会い、「何だこれは？」と思い、語源を知って納得する過程は、本資料が設計するランクシステムにおいて冒険者が独自命名型のランク名に出会う体験そのものである。

本資料は自らの設計思想を、自らの名前で体現している。

### 0-3. 対外名称との二層構造

|層|名称|機能|
|---|---|---|
|正式名称（内部）|Archiscatus|本資料体系の固有名。設計思想を凝縮した独自命名|
|対外名称（通称）|ランクシステム設計資料|初見で内容が伝わる即時理解型の呼称|

この構造は本編第2章で定義される二層構造、すなわち内部ランク（独自命名型）と対外ランク（即時理解型）の関係と同一である。ギルドが冒険者の内部ランクを対外ランクに翻訳して社会に提示するように、本資料はArchiscatusという正式名称を「ランクシステム設計資料」という対外名称に翻訳して読者に提示する。

読者が本資料を他者に紹介する際は、どちらの名称を使ってもよい。「ランクシステム設計資料」と言えば何の資料かが即座に伝わり、「Archiscatus」と言えば「何それ？」から会話が始まる。どちらを選ぶかは、場面と相手に応じて判断すればよい。
