## 第3章：対外ランクモジュール

### 3-1. 対外ランクテーブル

対外ランクはギルドが一般社会に向けて公開する簡易等級である。内部ランクの複雑な情報を、誰でも直感的に理解できる形に翻訳したものにあたる。依頼主が「このランク以上の冒険者を指名したい」と判断するための指標であり、市民がその冒険者にどの程度の信頼を置けるかを示す社会的な信用証明でもある。

対外ランクの段階数は作品の規模に応じて設計者が決定する。以下に代表的な三つの段階構成を示す。

|構成|段階数|ランク|想定用途|
|---|---|---|---|
|簡易構成|5段階|S・A・B・C・D|短編・ゲーム。説明を最小限にしたい場合|
|標準構成|7段階|S・A・B・C・D・E・F|中〜長編。最も汎用的|
|拡張構成|10段階|SS・S・A・B・C・D・E・F・G・H|大長編。細かい格差を描きたい場合|

対外ランクと内部のメインランクの対応関係は、作品ごとに設計者が定義する。必ずしも一対一対応である必要はなく、複数のメインランクが同じ対外ランクに集約されていてもよい。例えば龍姫式の9段階メインランクを標準構成の7段階対外ランクに対応させる場合、下位の二つのメインランクを同じ対外ランクにまとめるといった運用が可能である。

### 3-2. 閲覧権限と表示制御

対外ランクの最も重要な機能は「情報の制限」にある。内部で管理されている複雑な情報のうち、外部に出すべき情報だけを選別して表示する仕組みである。

チャームシステム（第2章 2-4節参照）との連動により、情報の閲覧範囲はかざす先の権限レベルによって自動制御される。

|権限レベル|対象|表示される情報|
|---|---|---|
|レベル1|一般市民・依頼主|対外ランクのみ|
|レベル2|冒険者同士|対外ランク＋メインランク＋サブランク＋パーティ指標|
|レベル3|ギルド施設のリーダー|全情報（罪業ランクを除く）|
|レベル4|ギルド上層部の専用リーダー|全情報|

この権限設計における要点は三つある。

一つ目は、レベル1で見える情報が対外ランクのみに絞られている点。依頼主は「Aランクの冒険者に頼みたい」とだけ言えばよく、その冒険者の内部構造を知る必要がない。これにより一般社会と冒険者社会の情報格差が自然に生まれ、二つの世界の間に境界線が引かれる。

二つ目は、レベル2で冒険者同士がメインランクとサブランクを相互参照できる点。これにより「お前、鵺の全盛か」「蓮の散華まで行ったらしい」といった冒険者間の符丁が成立し、独自命名型のランク名が作中の会話として自然に機能する。

三つ目は、罪業ランクがレベル4でしか閲覧できない点。通常のギルド施設でも罪業ランクは表示されないため、犯罪歴のある冒険者を外見上は識別できない。この不可視性が罪業ランクモジュール（第8章参照）の設計思想と連動している。
