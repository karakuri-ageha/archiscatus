## 第4章：特化型昇格試験

### 4-1. 標準昇格との差異

原典において特化型昇格は「試験は高難度」と記されている。本資料ではその高難度の内容を以下のように定義する。

| 項目    | 標準昇格試験     | 特化型昇格試験              |
| ----- | ---------- | -------------------- |
| 受験資格  | 全指標平均4.0以上 | 単一指標5.0かつ他平均3.0以上    |
| 必須試験  | 信用審査（＋面接）  | 信用審査（＋面接）＋特化指標対応試験   |
| 選択試験数 | 昇格先に応じた数   | 標準の選択試験数＋1           |
| 合格基準  | 各試験で合格判定   | 各試験で合格判定＋特化試験は最高評価必須 |
| 追加要件  | なし         | 特化分野でギルド審査官を唸らせる実演   |

特化型昇格の最大の特徴は、特化指標に対応する試験が必須に追加され、かつその試験で最高評価を得なければならない点にある。全方位に平均4.0以上を持つ標準昇格者が「穴のない実力」を証明するのに対し、特化型昇格者は「一つの分野における圧倒的な卓越」を証明しなければならない。

なお、特化型昇格における必須追加試験は、第3章 3-3節の同一試験の連続選択制限の対象外とする。特化分野における卓越の証明は昇格の核心要件であり、前回の選択履歴によって免除されるべきものではない。

なお、選択可能プール（全11モジュールから必須試験を除いた残り）から連続選択制限により前回選択分を除外した結果、残数が必要選択数を下回る場合がある。この場合、連続選択制限を以下のルールで緩和する。残数が必要選択数に満たない分に限り、前回選択した試験モジュールからの再選択を許可する。再選択の優先順位は受験者が決定する。この緩和は最上位ランクへの昇格など選択枠が最大化する場面で発生しうるものであり、通常の昇格では発生しない。

### 4-2. 特化指標と必須追加試験の対応

| 特化指標         | 必須追加試験        | 最高評価の基準                    |
| ------------ | ------------- | -------------------------- |
| 戦闘練度（CP）5.0  | 討滅試験（EX-SL）   | 審査官の想定を超える戦術で標的を討伐         |
| 知識深度（KD）5.0  | 調査試験（EX-RS）   | 報告書がギルドの公式資料として採用される水準     |
| 依頼完遂率（CC）5.0 | 護衛試験（EX-GD）   | 護衛対象から「この人以外に頼みたくない」と言わしめる |
| 地域貢献度（RC）5.0 | 長期駐在試験（EX-ST） | 駐在先の住民が離任を惜しむ水準の関係構築       |
| 信用等級（TR）5.0  | 仲裁試験（EX-MD）   | 対立する双方が判定に完全に納得する調停        |
| 生存適性（SV）5.0  | 単独行軍試験（EX-SM） | 審査官が設定した想定期間を大幅に短縮して帰還     |
| 指導実績（MT）5.0  | 同伴試験（EX-ES）   | 同伴した初心者がその後の成長で顕著な成果を出す    |
| 特殊功績（SP）5.0  | ※特化型昇格の対象外    | 下記注釈参照                     |

※特殊功績（SP）5.0について：SP5.0かつ全指標平均4.0以上の場合は自動昇格Bの条件を満たすため試験不要。SP5.0かつ他平均3.0以上4.0未満の場合、SPは個別認定による指標であり対応する試験モジュールが存在しないため、ギルド上層部の裁量による個別審査となる。

### 4-3. 特化型昇格の物語的意味

特化型で昇格した冒険者は、標準昇格者とは異なる物語を背負う。「何でもできる」のではなく「一つのことが圧倒的にできる」ことで上に立つ者は、その一つの分野で伝説を作る可能性がある。「あいつの昇格試験の討滅、見たか」「あの調査報告書は今でもギルドの教本に載ってる」といった語り草が生まれ、冒険者の異名（通称）の源泉にもなりうる。

一方で、特化型昇格者は弱点が明確であるという脆さも持つ。戦闘練度5.0で昇格した者が仲裁の場面で無力だったり、知識深度5.0で昇格した者がパーティ連携で足を引っ張ったりする。この凸凹がキャラクターの人間味を生み、パーティ編成における相互補完の必要性を物語レベルで駆動する。
